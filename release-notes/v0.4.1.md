The first published release of oxp3-tool: controller, sleep and display fixes for the ONEXPLAYER 3 (Intel Panther Lake, Arc B390) on Bazzite and CachyOS.

## Install

In Desktop Mode, open Konsole and run:

```bash
curl -fsSL https://raw.githubusercontent.com/Featherwolf/OXP3-Tool-for-Bazzite/HEAD/get.sh | sudo bash
sudo oxp3-tool status
sudo oxp3-tool apply
```

Or download `oxp3-tool` below, check it against `oxp3-tool.sha256`, and run it with `sudo python3 oxp3-tool`. From Game Mode, the [OXP3 Deck](https://github.com/Featherwolf/OXP3Deck) Decky plugin installs and runs it for you.

## What it does

- Fixes: `buttons`, `xbox-key`, `volume-keys`, `nvme-resume`, `oled-profile`, `xe-dsb-off`, plus experimental `xe-panel-replay-off`, `xe-hdr-backlight`, `inputplumber-suspend` and `gyro`. `status` shows which ones your machine needs; `revert` undoes exactly what `apply` changed.
- Button layout: any face key can open the Steam menu, Quick Access, Steam's keyboard, the Home screen, a frame-limit toggle, a screenshot or the OpenGamepadUI menu.
- CachyOS: `kernel`, `kernel try PACKAGE` and `kernel keep` switch Limine kernels safely without a keyboard.
- `--json` for front ends such as OXP3 Deck, and `diagnose` for bug reports.
